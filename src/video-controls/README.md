# video-controls

Transport/playback controls and the editor toolbar:
- `EditorToolbar.tsx` — the editor toolbar (includes the Export Project button).
- `MuteControl.tsx`, `VideoSizeDropdown.tsx`, `AspectRatioControls.tsx` — playback/size controls.
- `aspectRatios.ts` — aspect ratio definitions.
- `video-controls.css` — styles.
